# 数控 BUCK 降压可调电源（STM32F103C8T6）

ADC 采样输出电压与电流，TIM1 输出 20 kHz 互补 PWM，经半桥驱动控制同步整流 BUCK 主电路，通过闭环调节把输出稳定在设定值；0.96 寸 OLED 显示实时参数，4 个按键完成设置与启停，并带过压、过流保护。


![项目主电路](./原理图/屏幕截图%202026-09-16%20214057.png)

---

## 一、项目简介

本项目是一套数控降压（BUCK）可调直流电源，软硬件全部开源。单片机用 ADC 采集输出电压和输出电流，用 TIM1 输出 20 kHz 互补 PWM，经 IR2104S 半桥驱动芯片控制同步整流 BUCK 主电路，使输出电压跟随目标值；同时用 OLED 显示实时参数，用按键完成设置、启停与目标值增减，当输出超过阈值时自动断开继电器并关闭驱动使能。

- 主控芯片：STM32F103C8T6
- 开发环境：Keil MDK（工程文件 `USER/工程文件.uvprojx`）
- 依赖库：STM32F10x 标准外设库（`STLIB`），预定义宏 `USE_STDPERIPH_DRIVER`
- 主电路拓扑：同步整流 BUCK
- 显示：0.96 寸 OLED（软件 I2C）

## 二、功能特性

- 输出闭环可调：默认目标电压 10.00 V，按键以 0.1 V 步进增减
- 20 kHz 互补 PWM：由 TIM1_CH1（PA8）输出，死区 3 个时钟（约 41 ns），送入 IR2104S 的 PWM_IN
- 双路采样：ADC1 规则通道加 DMA1 循环搬运（PA0 电压、PA1 电流），TIM3 定时中断内累加求平均后换算为实际值
- 1 kHz 闭环调节：TIM1 更新中断每 20 次执行一次调节（20 kHz 除以 20 等于 1 kHz）
- 保护功能：输出电压超过 13.00 V 或输出电流超过 3.00 A 时，立即断开继电器、关闭驱动芯片使能、占空比清零并返回待机
- 人机交互：OLED 显示输出电压、输出电流、目标电压与运行状态，ADD / REDUCE / SET / MODE 四个按键
- 参数可校准：电压系数 `V_xishu` 为 9.9786，电流系数 `I_xishu` 为 1.04（定义在 `USER/main.h`）

## 三、硬件设计

原理图截图在 `原理图` 目录，各功能块与文件对应关系如下。

**供电与显示**

![LM2596 电源与 OLED 接口](./原理图/屏幕截图%202026-09-16%20214005.png)

12 V 输入经 SS54 防反接后送入 LM2596S-5.0 降到 5 V（47 uH 电感加 330 uF、100 nF 滤波），供运放、驱动芯片与 OLED 使用；OLED 四线接口为 SDA、SCL、3.3 V、GND。

**驱动电路**

![IR2104S 驱动电路](./原理图/屏幕截图%202026-09-16%20214011.png)

IR2104S 半桥驱动，PWM_IN 为占空比控制信号（经 1K 电阻接入 IN），PWM_SD 为芯片使能（经 1K 电阻接入 SD），自举二极管为 RS1M，自举电容 2.2 uF，HO、LO、VS 通过接插件 CN3 送往主电路。

**直流电压采样**

![直流电压采样电路](./原理图/屏幕截图%202026-09-16%20214017.png)

OPA2188 双运放构成的缩放电路，输入为 VOUT，输出为 VOUT1，按约 10 倍比例缩放，即输出 10 V 对应采样端 1 V，最大可测约 33 V，经运放跟随器送往单片机 ADC。

**直流电流采样**

![直流电流采样电路](./原理图/屏幕截图%202026-09-16%20214030.png)

低端采样方案，采样电阻 R11 实际焊接为 20 毫欧，配合 R12、R13 两个 9.1 欧电阻与 1 nF 电容滤波，送入 INA213AIDCKR 差分放大器（固定增益 50），输出 IOUT1 送单片机 ADC。

代码里的电流系数 `I_xishu` 为 1.04，与 20 毫欧采样电阻对应；原理图截图可能仍标注为 10 毫欧，以实际焊接的 20 毫欧为准。

**主电路**

![同步整流 BUCK 主电路](./原理图/屏幕截图%202026-09-16%20214057.png)

同步整流 BUCK 拓扑，高边与低边各用一只 IRF3205ZPBF（Q2、Q3），栅极分别由 HO、LO 驱动，电感 33 uH；输入侧滤波为 100 nF 与 220 uF 两只，输出侧为 220 uF 两只与 100 nF，输出经 VOUT 送电压采样电路，并通过采样电阻回流到地。

**主控最小系统**

![主控最小系统](./原理图/屏幕截图%202026-09-16%20214038.png)

STM32F103C8T6 最小系统，PA0、PA1 接采样电路，PA8、PA9 接驱动电路，PA10 接继电器驱动，PB0、PB1 接 OLED，PB12 到 PB15 接四个按键。

**继电器保护**

![继电器保护电路](./原理图/屏幕截图%202026-09-16%20214044.png)

SRD-05VDC-SL-C 继电器由三极管驱动，控制信号来自 PA10（原理图中网络名 protect），保护触发时断开输出回路；电源既可接到主控输入，也可接在继电器之后实现断电保护。

**按键电路**

![按键电路](./原理图/屏幕截图%202026-09-16%20214105.png)

ADD、REDUCE、SET、MODE 四个轻触按键，各带 100 nF 去抖电容。

## 四、引脚分配

- PA0：输出电压采样输入（ADC1_IN0，来自电压采样电路的 VOUT1）
- PA1：输出电流采样输入（ADC1_IN1，来自电流采样电路的 IOUT1）
- PA8：PWM 输出（TIM1_CH1，接 IR2104S 的 PWM_IN）
- PA9：驱动芯片使能（接 IR2104S 的 PWM_SD，对应宏 SD_ON 与 SD_OFF）
- PA10：继电器控制（对应宏 SW_ON 与 SW_OFF）
- PB0：OLED 数据线 SDA
- PB1：OLED 时钟线 SCL
- PB12：按键 ADD（目标电压增加）
- PB13：按键 REDUCE（目标电压减小）
- PB14：按键 SET（启动输出与闭环调节）
- PB15：按键 MODE（停止输出，返回待机）

### 运行流程

1. 上电初始化：延时、TIM1 PWM、ADC 加 DMA、继电器与驱动使能、按键、TIM3、OLED
2. 待机界面：继电器断开、驱动失能、闭环不工作，OLED 循环刷新电压、电流、目标值
3. 按 SET 键：接通驱动芯片使能与继电器，延时 500 ms 后进入运行界面
4. 运行界面：ADD 与 REDUCE 调整目标电压，SET 键启动闭环调节，MODE 键关闭输出返回待机
5. 任意时刻检测到过压或过流：立即断开输出，置保护标志并返回待机界面

### 两条后台链路

采样链路（TIM3 中断，约 5 ms 一次）

- ADC1 由 DMA 循环写入 `ADC_ConvertedValue[0]`（电压）与 `ADC_ConvertedValue[1]`（电流）
- 每次进入中断累加当前采样值，累计 300 次（约 1.5 s）后求平均并乘校准系数，更新 `DC_V` 与 `DC_I`

控制链路（TIM1 更新中断，20 kHz）

- 每 20 次更新中断（约 1 kHz）执行一次调节
- `pid_mode` 为 1 且未触发保护时：采样值低于目标则 `buck_pwm` 加 1，高于目标则减 1，并限幅在 0 到 3599，再写入 TIM1_CH1 比较寄存器
- `pid_mode` 为 0 或保护触发时：`buck_pwm` 清零并关闭 PWM 输出

说明：本工程实际使用的是上述比较加步进的调节方式；`HARDWARE/PID/pid.c` 中的位置式 PID 结构体与 `buck_pid` 函数当前未加入 Keil 工程编译，属于可选的升级方向。

### 关键参数

- `Target_V`：默认目标电压 10.00 V
- `V_yuzhi`、`I_yuzhi`：保护阈值 13.00 V、3.00 A
- `V_xishu`、`I_xishu`：换算系数 9.9786、1.04（其中电流系数 1.04 对应 20 毫欧采样电阻）
- `buck_pwm`：初值 500，范围 0 到 3599（TIM1 自动重装载值 3599，对应 20 kHz）

## 六、编译与烧录

1. 用 Keil uVision5 打开 `USER/工程文件.uvprojx`
2. 工程已选择器件 STM32F103C8，预定义宏 `USE_STDPERIPH_DRIVER`，源文件分为 CORE、HARDWARE、STLIB、USER、Readme 五个分组
3. 编译后输出到 `OBJ` 目录，产物为 `工程文件.hex` 与 `工程文件.axf`
4. 通过 SWD 接口下载（J-Link 或 ST-Link），下载后复位即可运行

提示：`OBJ` 目录是编译产物，`USER` 下的 `uvguix.*` 是各台电脑的界面布局文件，建议不要提交到仓库，本仓库已提供 `.gitignore`。

## 七、按键操作

- SET：待机界面按下开始输出；运行界面按下启动闭环调节
- ADD、REDUCE：目标电压加、减 0.1 V
- MODE：关闭输出并返回待机界面
- 保护触发后会自动回到待机状态，排除故障后重新按 SET 启动
